# Bereghici for glamour (gh, glab, glow)

Bereghici for [glamour (gh, glab, glow)](https://github.com/charmbracelet/glamour). It follows the macOS appearance live.

## Themes

| Theme | |

| [bereghici-light.json](themes/bereghici-light.json) | Bereghici Light |

## Usage

1. In your shell's startup: `export GLAMOUR_STYLE=~/.local/share/bereghici/ports/glamour/themes/bereghici-terminal.json`.

## Notes

gh, glab and glow render Markdown with glamour, which reads `GLAMOUR_STYLE`.
