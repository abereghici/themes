# Bereghici Light

Bereghici Light flavor for [Yazi](https://github.com/sxyazi/yazi). Generated from [abereghici/themes](https://github.com/abereghici/themes); do not edit.

Select it, with its dark counterpart, in `~/.config/yazi/theme.toml`:

```toml
[flavor]
dark = "bereghici-dark"
light = "bereghici-light"
```
