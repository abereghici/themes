## Usage

1. Open `chrome://extensions` and turn on Developer mode.
2. Load unpacked: `themes/bereghici-dark` or `themes/bereghici-light`.

## Notes

A Chrome theme has one set of colors, so it stays put when macOS switches. To follow the appearance instead, skip the theme and use Chrome's own color: New Tab → Customize Chrome → custom color `#263316` (Bereghici's accent), Mode → Device. Chrome derives both palettes from it, close to Bereghici rather than exact.
